Privacy Policy

Smart File Organiser is a Windows desktop utility that helps you organise files by extension and user-defined keywords. This policy explains how the application handles information.

Application: Smart File Organiser
Publisher: Guhan's Enterprises
Last updated: 27 October 2026
In short Smart File Organiser's core functionality runs locally on your computer. It does not require an account and, as designed, does not send the file information it processes to the publisher or to third-party services.

1. Introduction

This Privacy Policy applies to Smart File Organiser, published by Guhan's Enterprises (“we”, “us”, or “our”). We aim to explain clearly what information the application accesses and how it is used.

2. Information the application accesses

When you choose to organise files, the application may process file and folder details needed to carry out your instructions, such as:

  • File names and extensions;
  • Folder paths and file types; and
  • Keywords you enter for organising files.

This information is used locally to provide the file-organising features. The application does not require you to create an account or provide personal details to use its core functionality.

3. Collection and transmission

The application is designed to work offline. It does not include analytics, advertising, account sign-in, or cloud-processing features, and it does not transmit the file or folder information it processes to Guhan's Enterprises or third-party services.

The Microsoft Store may independently process information related to downloading, licensing, installing, or updating the application. Such processing is governed by Microsoft's applicable privacy terms.

4. How information is used

File and folder details are used only to perform actions you request, such as identifying files by extension, organising them into folders, and using keywords to determine organisation rules.

5. Storage and retention

File and folder information is processed locally on your device. The application does not upload your files to a remote server or maintain a remote copy of your file information. Files remain on your device unless you or an application action moves, renames, or deletes them.

Please keep backups of important files. You are responsible for reviewing file operations and maintaining copies of data you cannot afford to lose.

6. Sharing and advertising

We do not sell or share file information processed by the application. The application does not use that information for advertising, profiling, or marketing.

7. Security

Local processing helps avoid sending file information to an external service, but no software or device can be guaranteed completely secure. Keep your operating system updated, protect access to your device, and maintain backups of important files.

8. Children's privacy

The application does not knowingly collect personal information from children. It does not require an account and is not designed to transmit personal information to the publisher.

9. Your choices

You choose which files and folders to organise. You can stop using the application at any time. Because the application does not send your file information to us, we do not hold a remote copy of that information to access or delete on your behalf.

10. Changes to this policy

We may update this policy if the application or its data practices change. The latest version will be published at this same address, and the “Last updated” date will be revised when appropriate.
